# 🤖 Prácticas de Robótica
 
Repositorio con las prácticas de la asignatura Robótica movil, desarrolladas en Python sobre el entorno de simulación [Robotics Academy](https://jderobot.github.io/RoboticsAcademy/) (Gazebo + WebGUI).
 
## 📚 Prácticas
 
| Nº | Práctica | Descripción | Carpeta |
|----|----------|-------------|---------|
| 1 | Basic Vacuum Cleaner | Algoritmo simple de navegación para una aspiradora autónoma | [`Practica1/`](Practica1) |
| 2 | Follow Line | Coche  sigue lineas con controlador PID | [`Practica2/`](Practica2) |
| 3 | Obstacle Avoidance (VFF) | Navegación local con campos de fuerzas virtuales: el coche esquiva obstáculos y recorre el circuito pasando por todos los waypoints | [`Practica3/`](Practica3) |
 
 
## 🛠️ Herramientas
 
- Python 3
- Robotics Academy (JdeRobot)
- Gazebo y WebGUI para la simulación y la depuración visual
